SimulationCraft engine

        

        

          
          
        

        
The nightly Windows build comes from downloads.simulationcraft.org. This is the only time OfflineSim goes online; after it's installed everything runs offline. No internet on this PC? Download a simc-…-win64-….7z elsewhere and use "Install from a downloaded file".

        

      

      

        
OfflineSim updates

        

        

        
New versions are published on GitHub. Each one is signed; the app only installs an update whose signature matches the key built into it, and your data is never touched.
