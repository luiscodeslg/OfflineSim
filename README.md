# OfflineSim

A standalone Windows app for simming World of Warcraft characters, Raidbots-style, entirely on your own PC.
It is a desktop front end for the open-source [SimulationCraft](https://github.com/simulationcraft/simc) engine.

- **Quick Sim**: paste your `/simc` addon string and get DPS, an ability breakdown, buff uptimes and the full SimC HTML report.
- **Top Gear**: tick items from your bags and Great Vault; every combination (rings and trinkets as pairs) is simmed with profilesets and ranked.
- **Stat Weights**: scale factors for your primary and secondary stats, plus a ready-to-copy Pawn string.
- **APL Compare**: sim the same character with several action priority lists side by side.
- **APL Library**: the default APL for every class and spec, generated by your installed SimC build so it always matches the engine. Browse it as a readable table or raw text, duplicate it, edit it, and pick your version in any sim.
- **Advanced**: raw simc input for anything else (multiple actors, raid events, custom profilesets…).
- **Results**: every sim is kept locally; reopen, re-run or delete.

Fight style, length, boss count, precision (target error or fixed iterations) and extra simc options are all configurable.

## Running it

1. Download `OfflineSim.exe` and run it. No installer; it opens as a normal desktop window (it uses the Microsoft Edge WebView2 runtime that ships with Windows 10 and 11).
2. The first time, go to **Settings → Install / update latest nightly**. This downloads the current Windows x64 SimulationCraft nightly from `downloads.simulationcraft.org` and unpacks it. That is the only time the app goes online.
   - No internet on that PC? Download a `simc-XXXX-XX-win64-XXXXXXX.7z` from http://downloads.simulationcraft.org/nightly/ on another machine and use **Install from a downloaded .7z or .zip**.
   - Already have SimC? Put its path in **Use my own simc.exe**, or drop `simc.exe` next to `OfflineSim.exe`.
3. In game, type `/simc` (needs the [SimulationCraft addon](https://www.curseforge.com/wow/addons/simulationcraft)), copy the text, paste it into Quick Sim and press **Run**.

Update SimC after each WoW patch with the same Install button; the APL Library regenerates itself for the new build.

Data (settings, SimC build, custom APLs, results) lives in `%LOCALAPPDATA%\OfflineSim`. For a portable setup, create a folder named `data` next to `OfflineSim.exe` and it will be used instead.

Command line flags: `-browser` opens the UI in your default browser instead of an app window, `-data <dir>` picks the data folder, `-port <n>` fixes the local port.

## How custom APLs are applied

A custom APL's lines are appended after your character, and the first line of each action list is turned into an assignment (`actions.x=` instead of `actions.x+=`), so it replaces the default list rather than adding to it. Use **View simc input** on any sim page to see exactly what goes to simc.

## Updates

Installed copies update themselves. At launch and every two hours OfflineSim checks the latest [GitHub release](https://github.com/luiscodeslg/OfflineSim/releases/latest) for `manifest.json` + `manifest.sig`, downloads the new `OfflineSim.exe` if its build number is higher, and Settings shows **Restart and update**. Nothing is installed without your click, your data is never touched, and you can switch the checks off in Settings.

Updates are signed with Ed25519, the same scheme as the AzIdler desktop client:

- The public key (`update/public-key.pem`) is baked into the exe. Only the holder of the private key can publish an update.
- The app installs an update only if the signature verifies, the build number is higher than the running one (no rollbacks), and the downloaded exe matches the signed size and SHA-256.
- Downloads must be `https` and stay on GitHub hosts, including after redirects.

### Publishing updates (one-time setup)

OfflineSim has its own signing key pair; `update/public-key.pem` is the public half.

1. In this repo go to **Settings > Secrets and variables > Actions > New repository secret**. Name it `SIGNING_PRIVATE_KEY` and paste the full text of the private key file. (Anyone who can edit workflows could use that secret, so keep 2FA on and protect `main`.)
2. Push to `main`. The **Release** workflow tests, builds, signs and publishes `OfflineSim.exe`, `manifest.json` and `manifest.sig` as a release; the build number is the workflow run number.

The very first copy has to be downloaded by hand from the Releases page. If the key ever leaks, make a new one with `go run ./tools/keygen <file>` (it rewrites `update/public-key.pem`); every installed copy must then be replaced by hand once, because the public key is baked in.

## Building from source

Requires Go 1.25 or newer. Everything is pure Go (no cgo), so it cross-compiles from any OS.

```powershell
# On Windows
.\build.ps1
```

```sh
# On Linux/macOS
./build.sh            # writes dist/OfflineSim.exe (a dev build: it doesn't self-update)
```

Run the tests with `go test ./...`. For UI work you can run the server on any OS with `go run . -headless -port 8765` and open http://127.0.0.1:8765/ in a browser; `testdata/fake_simc.py` is a stand-in engine (made-up numbers, for exercising the UI only) and `testdata/e2e.js` drives every page with Playwright.

## Layout

| File | What it does |
| --- | --- |
| `main.go` | Startup, data folder, local server, app window |
| `platform_windows.go` | WebView2 window, icon, hidden simc console, low priority |
| `simc.go` | Finding, downloading, extracting and running simc; progress parsing |
| `sim.go` | Building simc input for each sim type, Top Gear combinations, history |
| `summary.go` | Reading simc's `json2` output into what the UI shows |
| `apl.go` | Class/spec list, default APL generation, custom APL storage, sample profiles |
| `profile.go` | Parsing the `/simc` addon string (character, equipped and bag items) |
| `selfupdate.go`, `internal/update/` | Signed self-update (check, verify, stage, swap exe) |
| `tools/keygen`, `tools/sign` | Make the signing key pair; sign a release manifest |
| `server.go` | Local HTTP API (bound to 127.0.0.1 only) |
| `web/` | The UI (plain HTML/CSS/JS, embedded in the exe) |

## Notes and limits

- Results are only as good as SimulationCraft's support for your spec; healer specs have limited support in SimC.
- Top Gear doesn't know item metadata, so it can't enforce unique-equipped, embellishment limits or two-hander vs. dual-wield rules. Deselect combinations that aren't legal.
- OfflineSim isn't affiliated with Raidbots, SimulationCraft or Blizzard. SimulationCraft is GPLv3 and downloaded separately.
